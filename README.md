# Roy T. Smart

I'm a PhD candidate in physics at Montana State University, advised by Charles Kankelborg.
I develop extreme ultraviolet snapshot imaging spectrographs, like the
[EUV Snapshot Imaging Spectrograph (ESIS)](https://roytsmart.github.io/research/esis.html),
which fly on NASA sounding rockets and measure the flow of plasma in the solar atmosphere.

Along the way I write open-source Python packages for modeling optical systems and analyzing solar data,
most of them in the [sun-data](https://github.com/sun-data) organization:
[named-arrays](https://github.com/sun-data/named-arrays),
[optika](https://github.com/sun-data/optika),
[ctis](https://github.com/sun-data/ctis),
and [more](https://roytsmart.github.io/software.html).
